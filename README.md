⏰ Python Alarm Clock

A desktop Alarm Clock application built using Python and Tkinter. It allows users to set an alarm and choose from different alarm sounds.

Features

- Set alarm time using hours, minutes, and seconds
- AM/PM selection
- Multiple alarm sound options
- Custom alarm tone selection
- Graphical user interface using Tkinter
- Alarm sound playback using Pygame

Technologies Used

- Python
- Tkinter
- Pygame
- Time and Datetime modules
- Threading
- File Dialog

🚀 How to Run

Clone this repository:

git clone https://github.com/ishaxplore/python-alarm-clock.git

Open the project folder in PyCharm.

Install Pygame:

python -m pip install pygame

Run the application:

python alarm_clock.py
